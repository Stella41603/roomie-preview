# Roomie preview

Static publishing copy of the no-login Roomie product preview.

Main development repository: [rayanitani/Roomie-Project](https://github.com/rayanitani/Roomie-Project).

Only the browser-delivered HTML is published here. This repository contains no database schema, server credentials, user records, or main-repository history. Preview data stays in each visitor's browser; it is not shared between users. Moving back to the main repository later only changes where the same static frontend is published; use the preview's Export backup / Import backup to move browser data between website addresses.
