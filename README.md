# Roomie preview

[Open Roomie](https://stella41603.github.io/roomie-preview/)

Generated frontend-only publishing copy of [rayanitani/Roomie-Project](https://github.com/rayanitani/Roomie-Project).

- `index.html`: the single standalone application.
- `app/` and `demo/`: small redirects for old bookmarks.
- `.nojekyll`, `_headers`, `_redirects`: GitHub Pages and Netlify hosting support.

Build the product in the source repository, then publish the contents of its `dist/` folder here. Keep this README and the publishing repository's Git history. Do not copy private source, configuration, database files, test output or user backups.

The app requires no login. Each visitor's data stays in their own browser; updating this repository does not synchronize roommate records. Export/import a backup to move records between website addresses.
